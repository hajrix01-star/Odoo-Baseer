# إضافات Baseer المخصصة

يحتوي هذا المجلد على موديولات Baseer التي نملكها ونطورها. كل موديول يوضع مباشرةً داخله، مثال: `baseer_web` أو `baseer_sale`. يحتوي `baseer_core` على نقطة الأساس ولا يحمل منطق أعمال.

لا نعدل موديولات Odoo الأصلية داخل `../odoo`. نستخدم الاعتمادية والوراثة لتوسيع النماذج والواجهات، ونضيف كل صلاحيات وقواعد وصول وبيانات انتقال ضمن الموديول المالك للسلوك.
